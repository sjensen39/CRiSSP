# CRiSSP
An ML algorithm using a custom and pre-trained CNN for food Classification of Risotto, Sushi, Steak, and Pizza (CRiSSP).
Created by: Sofie J and Sanya M

The first code cell specifies the data folder file path. Make sure that you rewrite the file path to match yours. The data folder can be downloaded from this Kaggle link: https://www.kaggle.com/datasets/ispritchin/food-4-pizza-risotto-steak-sushi
